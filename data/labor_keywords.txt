# 用工需求打分词库
# ---------------------------------------------------------------
# 规则打分引擎用这个文件给每家店打「用工需求分」(0-100)，不需要任何 AI、不花钱。
#
# 格式：每行 `关键词=分值`，分值可省略（用该分组的默认值）。注释行以 # 开头。
# 分组标记：
#   #B 基础分  —— 按菜系/业态定基准分。命中多个时取**最高**的一档。一个都没命中默认 45。
#   #P 加分项  —— 规模/体量信号，命中就累加。
#   #M 减分项  —— 小微店/外卖店信号，命中就累减（分值写负数）。
#   #N 夜间项  —— 夜宵/长营业时段信号，用工缺口通常更大，命中就累加。
#
# 匹配范围：商户名 + 高德/腾讯的分类名，包含即命中。
# 改完这个文件下次「开始分析」立即生效，不用重启。
#
# 调分思路：觉得跑出来的高分店太多 → 调低 #B 的基础分或调高 .env 里的
# LABOR_THRESHOLD；觉得某类店被低估 → 在 #B 里给它单独加一行。
# ---------------------------------------------------------------
